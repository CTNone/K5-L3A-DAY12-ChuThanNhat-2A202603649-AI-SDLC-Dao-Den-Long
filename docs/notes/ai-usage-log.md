# Nhật ký dùng AI (ước tính)

| Phase | Việc dùng AI | Token/chi phí ước tính |
|---|---|---|
| 1 | Đọc PRD, tách contract, viết mô phỏng và test | ~35k token |
| 2 | Map mới, dash/glide/wind, kiểm chứng | ~40k token |
| 3 | Fuel, shade AI, luật bình minh, evidence | ~45k token |
| 4 | Contract v1.3, leaderboard, soak/bench, GUI/accessibility, đóng gói | ~60k token |

Tổng ước tính: ~180k token. Chi phí quy đổi tùy nhà cung cấp; không dùng số token
để thay thế bằng chứng chạy thật. Các lần AI sai được ghi trong `docs/notes/phase-3-test-changes.md`
và phần giới hạn của `phase-4-spec.md`.
